Este projeto foi realizado de forma independente, usando a linguagem Python e o Google Colab.<br>
Foram primeiramente realizadas as analises tendo como base as listas fornecidas, e seguindo o passo a passo do Trello.<br>
Foram feitas algumas analises e testes de códigos a mais, conforme consta no projeto.<br>
Após as analises foram gerados os gráficos em cada seção, apenas os mais e menos vendidos não foram representados por gráficos.<br>
Os gráficos foram colocados novamente no final do projeto, logo antes do relatório com a opção escolhida para venda.<br>
O challenge foi ótimo para ajudar a acalmar o medo de não conseguir seguir no curso. Através dele foi possível ver que com<br>
o conteúdo do curso e um pouco de estudo em sites e na documentação da linguagem é possível sim realizar todos os exercícios propostos. <br>
Foram utilizados o w3schools e o site da documentação do próprio Python.<br>
Além dos muitos exercicios do curso de modelagem que ajudaram muito na resolução do mesmo.
